# 🏥 Hospital Management System

A web-based Hospital Management System developed to manage and organize various hospital operations through a simple and user-friendly interface.

## 🚀 Features

* Patient registration and management
* Doctor management and availability
* Appointment scheduling
* OPD patient management
* Emergency case handling
* Bed and room management
* Billing management
* Medical history records
* Department management
* Undo operations

## 🧠 Data Structures Used

The project applies Data Structures concepts to simulate and organize different hospital operations, including:

* **Queue** for patient and appointment management
* **Priority-based handling** for emergency cases
* **Stack** for undo operations
* **Tree-based structure** for organizing departments
* Additional concepts such as arrays, linked lists, searching, and sorting where required

## 💻 Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* XAMPP
* phpMyAdmin

## 🎯 Project Objective

The objective of this project is to combine web development with Data Structures concepts and demonstrate how different data structures can be applied to solve and manage real-world hospital operations.
